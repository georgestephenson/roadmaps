# Grouping Text

Title should really be Grouping Elements. These tags are used to group other elements together.

## `<div>` tag

Used to group "flow" content - no effect until styled or has a layout model like flexbox applied. Flow content includes most content that goes in the HTML body including text.

- Should be used when no other tag with more semantic meaning is appropriate
- Block-level element

## `<span>` content span tag

- Inline container element for content with no inherent semantic meaning
- Can be used for styling purposes
